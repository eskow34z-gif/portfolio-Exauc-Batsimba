# portfolio-Exauc-Batsimba

Portfolio d'Exaucé Batsimba Monekene, BTS SIO option SISR (IPSSI Val d'Europe).

Site React (Vite + Tailwind CSS + Motion), déployé automatiquement sur Vercel à chaque push sur `main`.

- `src/sections/` : une section du site par fichier (Hero, Profil, Compétences, Projets, Veille, Méthode, Innovation, Contact)
- `src/components/originkit/` : effets WebGL d'OriginKit (rubans de lumière, fibre optique, carte à points métalliques, bordure néon)
- `src/components/ui/` : composants 21st.dev (faisceaux animés, grille bento)
- `public/images/` : images des projets (`proxmox.png`, `stage-metm.png`)
- `PREPARATION_ORAL.md` : préparation à l'oral (non publiée)
- `ANTISECHE.md` : explications simples de chaque notion du site (non publiée)

Développement local : `npm install` puis `npm run dev`.
